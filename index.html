A live compiler and JIT runtime for Rust, written in Rust

Rust without the wait.

rustc builds your program, then you run it. Relax runs your program while it builds it.

Relax runs a Cargo package straight from source, with no rustc, LLVM or linker in the loop. It checks your code, compiles each function the moment it is first called, optimises the hot ones while the program runs, and patches new code into the running process when you save a file.
